# Shift hand-over template

```
Shift:      Night 22:00-06:00   Date: YYYY-MM-DD
From:       name            To: name

1. Overall status
   Green / Amber / Red - one line summary.

2. Open incidents (highest priority first)
   INC#   P   Service        Status / next step              Owner / waiting on
   ...

3. Major incidents / bridges
   Active? Bridge details, next update time.

4. Changes in progress or starting this shift
   CHG#   Window        What to watch (expected alerts)   Implementer contact

5. Batch / scheduled jobs
   Late, failed or rerun jobs; deadlines at risk.

6. Monitoring
   Alerts acknowledged but not resolved, flapping alerts, monitoring gaps.

7. Watch list
   Things that aren't incidents yet but could become one (disk growing, certificate expiring).

8. Notes for the team
   New procedures, tool issues, contacts changed.
```

## Rules

- Written first, then a **short verbal walk-through** so the next shift can ask questions.
- Nothing important lives only in someone's memory or chat.
- The incoming person confirms they've taken ownership of each open item.
